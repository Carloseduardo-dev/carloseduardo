Aplicar um GRID DE FUNDO GLOBAL em todo o site, inspirado no design oficial do Next.js / Vercel.

────────────────────────────────────
OBJETIVO
────────────────────────────────────
Criar um fundo com grade sutil e elegante que cubra TODA a página, do topo ao rodapé, sem interferir no conteúdo.

────────────────────────────────────
REQUISITOS VISUAIS
────────────────────────────────────
- Grid discreto (linhas ou pontos)
- Aparência moderna e profissional
- Estilo tech/minimalista
- Baixo contraste
- Não competir com textos ou imagens

────────────────────────────────────
IMPLEMENTAÇÃO TÉCNICA
────────────────────────────────────
- O grid deve ser aplicado no <body> ou em um wrapper global
- Usar apenas CSS (background-image)
- NÃO usar imagens externas
- NÃO usar canvas

Exemplo de abordagem permitida:
- linear-gradient
- radial-gradient
- combinação de múltiplos backgrounds

────────────────────────────────────
COMPORTAMENTO
────────────────────────────────────
- Grid fixo no fundo (background-attachment: fixed ou pseudo-elemento)
- Conteúdo rola normalmente sobre o grid
- Grid NÃO se move com o scroll
- Não causar layout shift

────────────────────────────────────
TEMA CLARO / ESCURO
────────────────────────────────────

Dark Mode:
- Fundo: #0a0a0a ou #000
- Grid: linhas/pontos em cinza escuro (#1f1f1f ou #222)
- Opacidade baixa (5%–10%)

Light Mode:
- Fundo: #ffffff ou #fafafa
- Grid: cinza claro (#e5e5e5)
- Opacidade baixa

────────────────────────────────────
RESPONSIVIDADE
────────────────────────────────────
- Funcionar em telas grandes e pequenas
- Em mobile:
  - Reduzir opacidade do grid
  - Evitar poluição visual

────────────────────────────────────
REGRAS IMPORTANTES
────────────────────────────────────
- NÃO alterar layout existente
- NÃO alterar textos
- NÃO alterar componentes
- Manter performance alta
- Manter identidade GitHub / Next.js

Resultado esperado:
Um fundo sofisticado com grid contínuo em TODA a página, visível porém sutil, transmitindo profissionalismo e tecnologia.
