Aplicar um FUNDO GLOBAL AVANÇADO em TODO o site, inspirado no design oficial do Next.js / Vercel,
com GRID + GRADIENT RADIAL SUAVE + INTERAÇÃO LEVE COM O MOUSE.

────────────────────────────────────
OBJETIVO
────────────────────────────────────
Criar um fundo tecnológico, moderno e sofisticado que cubra TODA a página, transmitindo
profissionalismo e alto nível técnico, sem competir com o conteúdo.

────────────────────────────────────
CAMADA 1 — FUNDO BASE
────────────────────────────────────
- Fundo sólido
  Dark mode: #0a0a0a ou #000000
  Light mode: #ffffff ou #fafafa

────────────────────────────────────
CAMADA 2 — GRID (GRADE)
────────────────────────────────────
- Grid feito apenas com CSS (linear-gradient ou radial-gradient)
- Linhas finas ou pontos
- Baixíssima opacidade
- Grid fixo no fundo (não rola com o conteúdo)

Configuração esperada:
- Espaçamento entre linhas: 40px–60px
- Espessura: 1px
- Cor:
  Dark: rgba(255,255,255,0.05)
  Light: rgba(0,0,0,0.05)

────────────────────────────────────
CAMADA 3 — GRADIENT RADIAL SUAVE
────────────────────────────────────
- Um gradient radial central ou levemente deslocado
- Cria profundidade sem chamar atenção
- Deve misturar suavemente com o grid

Exemplo visual:
- Centro levemente mais claro
- Bordas mais escuras

────────────────────────────────────
CAMADA 4 — INTERAÇÃO COM O MOUSE
────────────────────────────────────
- O gradient radial deve reagir suavemente à posição do mouse
- Movimento sutil, com easing
- Não seguir exatamente o cursor (efeito de inércia)
- NÃO usar bibliotecas externas pesadas

Implementação permitida:
- CSS variables atualizadas via JS
- requestAnimationFrame
- Framer Motion (se já estiver no projeto)

────────────────────────────────────
COMPORTAMENTO GERAL
────────────────────────────────────
- Grid e gradient ficam FIXOS no fundo
- Conteúdo rola normalmente por cima
- Não causar re-render pesado
- Performance otimizada

────────────────────────────────────
RESPONSIVIDADE
────────────────────────────────────
- Em mobile:
  - Reduzir opacidade do grid
  - Reduzir intensidade do gradient
  - Desativar interação com mouse (touch devices)

────────────────────────────────────
TEMA (DARK / LIGHT)
────────────────────────────────────
- Integrar com o toggle de tema existente
- Cores do grid e gradient devem mudar conforme o tema
- Transição suave entre temas (300ms–500ms)

────────────────────────────────────
REGRAS IMPORTANTES
────────────────────────────────────
- NÃO alterar layout existente
- NÃO alterar textos
- NÃO alterar componentes
- NÃO usar imagens externas
- NÃO usar canvas
- Apenas CSS + JS leve

────────────────────────────────────
RESULTADO ESPERADO
────────────────────────────────────
Um fundo premium, tecnológico e moderno, com grid contínuo em toda a página,
gradient sutil e interação leve com o mouse, no nível visual do site oficial do Next.js.
